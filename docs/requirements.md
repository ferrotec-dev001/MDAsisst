# MDAsisst 要件定義書

## 1. 概要
MDAsisst は、Markdownの記述サポート、チートシート表示、リアルタイムプレビュー、スニペット補完、および高度な半透明ウィンドウ制御を提供する Windows デスクトップアプリケーション (C# / WPF) です。

## 2. 対象プラットフォーム・技術スタック
- **プラットフォーム**: Windows 10 / 11 デスクトップアプリケーション
- **言語 / フレームワーク**: C#, .NET 8, WPF (Windows Presentation Foundation)
- **パッケージング / インストーラー**: WiX Toolset または ClickOnce / Inno Setup によるインストーラー作成

## 3. 主な機能要件
1. **Markdown文法サポート**
   - チートシートや文法ガイドの表示
   - 記載後の効果表示（リアルタイムプレビュー）
   - 入力サポート（スニペット補完、自動補完）
2. **ウィンドウ＆アピアランス制御**
   - 半透明ウィンドウ（透過度調整可能）
   - 任意の位置への移動、任意のサイズ変更
   - アピアランス設定: ウィンドウ色調整、フォント調整、フォント色調整
   - 起動後は表示時半透明、非表示時トレイに最小化
   - 常駐設定、最前面設定
   - 編集時の自動ウィンドウ表示、非編集時に画面右上／右下への自動最小アイコン表示
   - 編集／非編集時の自動ウィンドウ変化の時間設定
   - アップデート設定（自動 / 手動 / 不要）
3. **オフライン動作**
   - インターネット未接続環境でも完全動作すること（ローカルリソースのみでの実行）

## 4. 非機能要件
1. **インストーラー**: Windowsインストーラーの提供
2. **パフォーマンス**: メモリ消費の最小化（軽量動作）
3. **オフライン耐性**: ネットワーク接続なしでの完全機能動作
4. **自動アップデート**: GitHub リポジトリ（Releases等）上の最新バージョン検知と自動アップデート機能（有効時）
