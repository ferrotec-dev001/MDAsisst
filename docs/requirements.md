# MDAsisst 要件定義書

- 文書ID: REQ-MDAsisst
- 版数: 2.0
- 最終更新: 2026-08-05
- 承認者: 中村勝（株式会社フェローテック）
- 管理方式: MD駆動設計（本ファイルが唯一の正。実装・テストは本書に従う）

---

## 1. 目的・背景

Markdown は社内文書・AI連携プロンプト・設計書の標準記法となりつつあるが、記法の暗記負荷と
「書いた結果どう表示されるか」の確認コストが利用の障壁になっている。
MDAsisst は、**画面の隅に半透明で常駐し、書きながら記法を確認・補完できる支援ツール**を提供し、
この障壁を取り除くことを目的とする。

## 2. スコープ

| 区分 | 内容 |
| --- | --- |
| 対象 | Windows 10 / 11 (x64) 上で動作する単独デスクトップアプリ |
| 対象ユーザー | Markdown を日常的に書く社内従業員（初学者〜中級者） |
| 非対象 | Web版・Mac/Linux版、共同編集、クラウド同期、Markdown以外の記法 |

## 3. 確定した設計判断（ADR）

本要件に影響する重要決定は `docs/adr/` に記録する。要約:

| ID | 決定 | 理由 |
| --- | --- | --- |
| ADR-0001 | **自己完結型エディタ**（アプリ内でMDファイルを開いて編集・プレビュー） | 外部エディタ監視方式より仕様が明確で、補完・チートシート連携が自然 |
| ADR-0002 | プレビューは **WPF FlowDocument** で描画（WebView2 不使用） | 「メモリ最小」「完全オフライン」要件を最優先。追加ランタイム不要 |
| ADR-0003 | 配布・更新は **Velopack** | インストーラーと差分自動更新を一体提供、GitHub Releases 連携が標準装備 |

## 5. 機能要件

記法: **[必須]** = UAT必須項目 / **[推奨]** = 実装するが優先度中

### 5.1 エディタ（FR-ED）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-ED-01 | `.md` / `.markdown` ファイルを開く・保存する・名前を付けて保存する | 必須 |
| FR-ED-02 | 新規作成、および未保存変更がある状態での終了時に確認ダイアログを出す | 必須 |
| FR-ED-03 | 等幅フォントでの編集、行番号は任意表示（既定OFF） | 推奨 |
| FR-ED-04 | Undo/Redo、検索・置換（アプリ内） | 推奨 |
| FR-ED-05 | 直近に開いたファイル履歴（最大10件）を保持し再オープンできる | 推奨 |
| FR-ED-06 | 自動保存（任意ON、既定OFF、間隔設定可） | 推奨 |
| FR-ED-07 | 文字コードは UTF-8（BOM無し）を既定とし、BOM付き/CRLF-LF を保持して保存する | 必須 |

### 5.2 チートシート・記法ガイド（FR-CS）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-CS-01 | Markdown 記法の一覧をカテゴリ別（見出し/装飾/リスト/リンク/コード/表/引用/その他）に表示する | 必須 |
| FR-CS-02 | 各記法について「記述例」と「記載後の効果（レンダリング結果）」を並べて表示する | 必須 |
| FR-CS-03 | チートシート項目のクリックで、エディタのカーソル位置にスニペットを挿入する | 必須 |
| FR-CS-04 | チートシートをキーワードで絞り込み検索できる | 推奨 |
| FR-CS-05 | チートシート定義はアプリ内蔵JSONで保持し、オフラインで完全に参照できる | 必須 |
| FR-CS-06 | ユーザー独自スニペットを追加・編集・削除できる（設定フォルダに保存） | 推奨 |

### 5.3 リアルタイムプレビュー（FR-PV）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-PV-01 | 編集中の内容を入力に追従してプレビュー表示する（デバウンス既定250ms、設定可） | 必須 |
| FR-PV-02 | 対応記法: 見出し1-6/段落/強調・強勢/取消線/箇条書き・番号付きリスト/タスクリスト/引用/インラインコード/コードブロック/表/水平線/リンク/画像/改行 | 必須 |
| FR-PV-03 | エディタとプレビューのスクロール位置を同期する | 推奨 |
| FR-PV-04 | 表示レイアウトを「エディタのみ／プレビューのみ／左右分割」から選択できる | 必須 |
| FR-PV-05 | プレビュー内のリンクは既定ブラウザで開く（オフライン時もアプリは落ちない） | 推奨 |
| FR-PV-06 | 画像はローカル相対パスを解決して表示する。解決不可時は代替テキストを表示 | 推奨 |

### 5.4 入力サポート（FR-IA）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-IA-01 | トリガー文字（`#`, `-`, `>`, `` ` ``, `[`, `|` 等）入力時に候補ポップアップを表示する | 必須 |
| FR-IA-02 | リスト行での Enter による自動連番・自動箇条書き継続、空項目での自動解除 | 必須 |
| FR-IA-03 | 選択範囲に対する装飾トグル（Ctrl+B=太字、Ctrl+I=斜体、Ctrl+K=リンク） | 必須 |
| FR-IA-04 | 表の入力補助（行列数を指定して雛形挿入） | 推奨 |
| FR-IA-05 | 補完候補は Esc で閉じ、Tab/Enter で確定。IME入力中は補完を抑止する | 必須 |

### 5.5 ウィンドウ・アピアランス（FR-WN）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-WN-01 | 起動後はメインウィンドウを半透明で表示する | 必須 |
| FR-WN-02 | ウィンドウは任意の位置へドラッグ移動できる | 必須 |
| FR-WN-03 | ウィンドウは四辺・四隅から任意にサイズ変更できる | 必須 |
| FR-WN-04 | 透過度を 20%〜100% の範囲で無段階調整できる | 必須 |
| FR-WN-05 | ウィンドウ背景色を任意に設定できる | 必須 |
| FR-WN-06 | フォント（種類・サイズ）を編集領域／プレビュー領域それぞれに設定できる | 必須 |
| FR-WN-07 | フォント色を設定できる | 必須 |
| FR-WN-08 | 常駐設定（Windows起動時に自動起動する／しない）を切り替えられる | 必須 |
| FR-WN-09 | 最前面表示（Topmost）を切り替えられる | 必須 |
| FR-WN-10 | 閉じるボタン／最小化でタスクトレイに格納し、トレイアイコンから復帰できる | 必須 |
| FR-WN-11 | **編集時の自動表示**: 入力・フォーカスを検知して最小アイコン状態から自動でウィンドウを展開する | 必須 |
| FR-WN-12 | **非編集時の自動最小化**: 無操作が続いたら画面の右上または右下（設定で選択）へ最小アイコン化する | 必須 |
| FR-WN-13 | 自動展開／自動最小化までの待ち時間をそれぞれ秒単位で設定できる（既定: 展開 即時 / 最小化 30秒、0=無効） | 必須 |
| FR-WN-14 | 自動変化はフェードアニメーションで行い、アニメーション無効設定も持つ | 推奨 |
| FR-WN-15 | ウィンドウ位置・サイズ・レイアウトを終了時に保存し次回起動時に復元する。画面外に出た場合は作業領域内に補正する | 必須 |
| FR-WN-16 | マルチモニタ・DPIスケーリング（100%〜200%）環境で位置計算が破綻しないこと | 必須 |
| FR-WN-17 | アピアランス設定はプリセット（ダーク／ライト／高コントラスト）から選択でき、変更は即時反映される | 推奨 |

### 5.6 設定・更新（FR-ST）

| ID | 要件 | 区分 |
| --- | --- | --- |
| FR-ST-01 | 設定は `%APPDATA%\MDAsisst\settings.json` に保存する（人間が読める形式） | 必須 |
| FR-ST-02 | 設定ファイルが破損・欠損している場合は既定値で起動し、破損ファイルを退避する | 必須 |
| FR-ST-03 | 設定画面から全設定を初期化できる | 推奨 |
| FR-ST-04 | 更新方式を「自動／手動／不要」から選択できる（既定: 手動） | 必須 |
| FR-ST-05 | 「自動」時は起動から一定時間後にバックグラウンドで GitHub Releases を確認し、更新があれば適用して次回起動時に反映する | 必須 |
| FR-ST-06 | 「手動」時は設定画面の「更新を確認」ボタンでのみ確認する | 必須 |
| FR-ST-07 | 「不要」時は一切ネットワークアクセスを行わない | 必須 |
| FR-ST-08 | 更新確認の失敗（オフライン・API制限・404等）はアプリ動作に影響させず、ログ記録のみとする | 必須 |
| FR-ST-09 | 現在のバージョンとリリースノートへのリンクを設定画面に表示する | 推奨 |

## 6. 非機能要件（NFR）

| ID | 分類 | 要件 | 検証方法 |
| --- | --- | --- | --- |
| NFR-01 | 配布 | Windows 向けインストーラー（exe）を提供し、管理者権限なしでインストールできる | 実機インストール |
| NFR-02 | 性能 | 待機時（最小アイコン状態）のワーキングセットが 120MB 以下、通常編集時 200MB 以下 | タスクマネージャ／診断ツールで計測 |
| NFR-03 | 性能 | 起動からウィンドウ表示まで 2 秒以内（2回目以降の起動、標準的な社内PC） | ストップウォッチ計測 |
| NFR-04 | 性能 | 10,000 行の Markdown 編集時、入力からプレビュー反映まで 500ms 以内 | 負荷テスト |
| NFR-05 | 可用性 | インターネット未接続でも全機能（更新確認を除く）が動作する | ネットワーク遮断テスト |
| NFR-06 | 保守性 | `docs/` 配下のMDドキュメントを唯一の設計正とし、コード変更時に必ず同期更新する | レビュー |
| NFR-07 | 品質 | ドメインロジック（レンダラ／補完／設定／自動表示判定）は単体テストで正常系・境界値・異常値を網羅する | xUnit 実行 |
| NFR-08 | 機密 | 編集内容・ファイルパス等を外部送信しない。通信は更新確認（GitHub）のみ | コードレビュー・通信ログ |
| NFR-09 | ログ | ログは `%APPDATA%\MDAsisst\logs\` にローテーション保存（既定7日）。個人情報・本文は記録しない | 実機確認 |
| NFR-10 | 更新 | 自動更新は差分適用とし、更新失敗時も既存バージョンで起動できる | 更新テスト |

## 7. 制約事項

- 本プロジェクトの情報取扱いは `Agent.MD` の機密保持条項に従う（社外流出の禁止）。
- コード署名証明書は現時点で未手配。初回インストール時 SmartScreen 警告が出る前提で運用手順書に記載する（課題 ISS-001）。

## 8. UAT（受入テスト）の合格条件

1. 上表の **[必須]** 要件がすべて実機で確認できること。
2. NFR-02 / NFR-03 / NFR-05 を実測で満たすこと。
3. インストーラーからのクリーンインストール → 起動 → 編集 → 終了 → 再起動で設定が保持されること。
4. 既知の未解決不具合が「軽微」以下であること。

## 9. 用語

| 用語 | 定義 |
| --- | --- |
| 最小アイコン状態 | ウィンドウを閉じずに画面隅の小アイコンへ縮小した状態。トレイ格納とは別 |
| 常駐 | Windows ログオン時に自動起動し、トレイに待機する動作 |
| デバウンス | 連続入力中は処理をまとめ、入力が止まってから実行する遅延処理 |
