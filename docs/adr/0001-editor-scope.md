# ADR-0001: MDAsisst を自己完結型エディタとする

- ステータス: 承認済み
- 決定日: 2026-08-05
- 決定者: 中村勝

## 背景

初期構想では「編集中の Markdown ファイル」を支援するとされていたが、
①アプリ内で編集する（自己完結型）のか、②VSCode 等の外部エディタを監視して支援するのかが未確定だった。
この選択はアーキテクチャ全体（ファイル監視、フォーカス検知、補完の実現手段）を左右する。

## 決定

**自己完結型エディタ**とする。MDAsisst 自身が `.md` ファイルを開き、編集し、保存する。
プレビュー・チートシート・スニペット補完はすべて自アプリのエディタに対して働く。

## 理由

- 外部エディタ監視方式は、補完（キー入力への介入）を他プロセスへ注入する必要があり、
  実現手段が限定的でセキュリティソフトに阻害されるリスクが高い。
- 「編集時の自動ウィンドウ表示／非編集時の自動最小化」の判定が、自アプリ内のイベントだけで完結し、
  仕様が明確かつテスト可能になる。
- オフライン・低メモリ要件と両立しやすい。

## 影響

- 外部エディタ利用者にとっては「MDAsisst に切り替えて書く」運用になる。
- FileSystemWatcher による外部変更検知は、将来拡張（第2フェーズ候補）として保留する。
- エディタ品質（Undo/Redo、検索置換、IME 挙動）が製品価値に直結するため、優先度を上げる。
