# ADR-0013: MSI インストール時のファイルパーミッション（ACL）の明示的制御と手動削除性確保

## Status
Accepted

## Context
v0.3.2 / v0.3.3 において、`--instLocation PerMachine`（Program Files配下）でインストールされたアプリケーションファイルの `MDAsisst.dll` 等が、管理者権限（Administrators）であっても手動削除時に `UnauthorizedAccessException`（アクセス拒否）となる現象（ISS-017）が発生した。
これは、Velopack が生成する WiX MSI インストーラーがファイル配置時に付与するデフォルトのパーミッション（DACL）が原因であり、既存のバージョンの上書き更新時や手動クリーンアップ時にファイルの置き換え・削除が阻害され、インストール失敗を引き起こす。

## Decision
1. MSIインストーラーによるファイル配置時、 Administrators や System によるフルコントロールおよび通常の運用に必要な書き込み・削除権限が適切に保証されるよう、ビルドプロセスまたはインストーラー設定を見直す。
2. Velopack 標準の MSI 生成フローにおいてファイルアクセス権限がロックダウンされないよう対策を講じる、あるいはカスタムアクション/WiXパラメータによるパーミッション明示化を検討する。
3. ユーザーが万が一の手動復旧やクリーンインストールを行う際にも Program Files 配下のファイルアクセス拒否に悩まされない構造を維持する。

## Consequences
- インストール先ファイルのロックや権限起因の削除失敗を防ぎ、上書きインストールやアンインストールが確実に実行できるようになる。
