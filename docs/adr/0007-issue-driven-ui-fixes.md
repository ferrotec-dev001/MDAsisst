# ADR-0007: Issue #1〜#10 対応方針とオンラインアップデート準備

- ステータス: 承認済み・実装済み
- 決定日: 2026-08-05
- 起票: GitHub Issue #1〜#10（UAT前レビューでの指摘）

## 背景

UAT前レビューとして、GitHub Issue に10件の改善要望・不具合が登録された。
本ADRは各Issueへの対応方針と実装箇所を記録し、対応完了後に v0.2.0 としてオンライン
アップデート経由で配布する。

## 対応一覧

| Issue | 内容 | 原因 | 対応 |
| --- | --- | --- | --- |
| #1 | 透過度を変更してもすぐに反映されない | 設定は「OK」押下時のみ `ApplyAppearance()` を呼んでいた | `SettingsWindow` にライブプレビュー機構を追加。スライダー操作の都度 `onLivePreview` コールバックで即時反映。キャンセル時はスナップショットから復元 |
| #2 | 色指定がカラーコード入力で不便 | `#RRGGBB` のテキスト入力のみ | `System.Windows.Forms.ColorDialog` を用いた色選択ボタン＋現在色のスウォッチ表示を追加（`UseWindowsForms=true`） |
| #3 | 終了時に不要な保存確認が出る | `MainViewModel.OnTextChanged` が `Text` セット時に必ず `IsDirty=true` にする実装のため、ファイルを開いた直後に `Editor.Text` を同期する処理が誤って「変更あり」を立てていた | `MainWindow` にプログラム的な読み込み中を示す `_suppressChangeTracking` フラグを追加し、Open/New 時は変更検知を抑止 |
| #4 | アプリアイコン未設定、トレイ格納時にアイコンが見えない | アイコンファイル自体が存在しなかった | `Assets/icon.ico` を新規作成し `ApplicationIcon` に設定。`TaskbarIcon.IconSource` にも明示設定 |
| #5 | チートシートが検索前提で初心者に使えない | 一覧はあったが「検索して探す」UIの体裁だった | 検索窓を廃止し、全カテゴリ・全項目を常時アイコンボタンとして表示。ボタン表記に実際のMD記法（例: `#`, `**B**`, `> `）を用いる |
| #6 | メニューの配置 | 新規/開く/保存等が専用のツールバー行を占有 | ツールバー行を廃止し、タイトルバー内にアイコンボタンとして統合（ADR-0004の半透明タイトルバーの一部として） |
| #7 | ステータスバー不要、バージョンは設定内へ | 下部に常時ステータスバーを表示していた | ステータスバー行を削除。状態メッセージはタイトルのツールチップに変更。バージョン表示は「設定」画面のみに一本化（既存） |
| #8 | エディタ・プレビューの配置 | 左右分割で、あまり入力しない用途に対して非効率 | 左側を「上=エディタ／下=プレビュー」の上下分割に変更し、右側のチートシート領域を広く確保 |
| #9 | 最小化アイコンが大きい | 180×34 の帯状ウィンドウで復帰導線としては過大 | 44×44 のアイコンのみの正方形ウィンドウに変更 |
| #10 | 設定ウィンドウのタイトルバーがアプリ本体と統一されていない | 標準の Windows タイトルバーを使用していた | `WindowChrome` によるカスタムタイトルバーをメインウィンドウと同一デザインで適用 |

## オンラインアップデートの準備

上記対応を反映したビルドを **v0.2.0** としてタグ付けし、`.github/workflows/release.yml`
経由で GitHub Releases に公開する。既存インストール済みユーザーは：

- 更新方式が「自動」: 起動後1日以内に自動検知・ダウンロードし、次回終了時に適用
- 更新方式が「手動」（既定）: 「設定」→「アップデート」タブの「更新を確認」を押すと即座に取得可能

配布経路・パッケージID（`Ferrotec.MDAsisst`）は変更していないため、**差分パッケージによる
オンラインアップデートがそのまま機能する**（`docs/release.md` の手順どおり）。
