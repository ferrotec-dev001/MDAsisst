# MDAsisst 操作説明書

- 版数: 1.1
- 発行日: 2026-08-05（v1.1: ADR-0009 に伴うインストール・更新手順の改訂）
- 対象読者: MDAsisst を利用するすべての方（専門知識不要）

---

## 1. はじめに

### 1.1 本書の目的・対象読者

本書は、Markdown 記述支援ツール **MDAsisst** のインストールから日常操作、トラブル発生時の
対処までを、専門知識がない方でも実施できるようにまとめたものです。

### 1.2 対象プログラム名・バージョン

| 項目 | 内容 |
| --- | --- |
| プログラム名 | MDAsisst |
| 対象バージョン | v0.3.0 以降（Program Files への per-machine インストール、ADR-0009） |
| 開発元 | 株式会社フェローテック |
| 配布元 | https://github.com/ferrotec-dev001/MDAsisst （社内限定） |

---

## 2. 動作環境

### 2.1 必要な PC/OS 環境

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10 (64bit) / Windows 11 |
| .NET ランタイム | **不要**（自己完結型パッケージのため別途インストール不要） |
| メモリ | 空き 200MB 以上を推奨 |
| ディスク | インストールに約 150〜250MB |
| ネットワーク | 必須ではない（完全オフラインで動作）。自動更新機能を使う場合のみ必要 |

### 2.2 前提となる設定

**v0.3.0 以降、管理者権限が必要です**（ADR-0009）。`Program Files\Ferrotec Corporation\MDAsisst`
へインストールするため、インストール時・更新適用時のいずれも Windows の管理者権限確認（UAC）
が表示されます。社内PCで管理者権限が制限されている場合は、情報システム部門にインストールを
依頼してください。

## 3. インストール・セットアップ手順

### 3.0 【重要】v0.2.x をお使いだった方の移行手順

v0.2.x までは個人フォルダ（`%LocalAppData%\Ferrotec.MDAsisst`）にインストールされていました。
v0.3.0 はインストール先が変わるため（ADR-0009）、**新しい `.msi` を入れる前に、必ず旧バージョンを
削除してください**。削除せずに新版を入れると、旧版と新版の2つが同居し、ショートカットの重複や
旧版の自動更新が動くなどの不具合が起こります。

1. アプリが起動していれば終了します（タスクトレイのアイコンを右クリック →「終了」）。
   タスクマネージャーに `MDAsisst.exe` / `Update.exe` が残っていないことも確認してください。
2. 「設定」→「アプリ」→「インストールされているアプリ」から **MDAsisst** をアンインストールします。
3. 念のため、エクスプローラーのアドレス欄に `%LocalAppData%` と入力して開き、
   **`Ferrotec.MDAsisst`** フォルダが残っていれば削除します。
4. その後、3.1 の手順で `.msi` からインストールしてください。

> **設定は引き継がれます。** 設定ファイルは `%APPDATA%\MDAsisst\settings.json`（インストール先とは
> 別の場所）に保存されているため、上記の手順で消えることはありません。透過度・色・フォント等の
> 設定はそのまま新バージョンに引き継がれます。

### 3.1 インストール手順

1. 社内共有の配布先（GitHub Releases）から **`Ferrotec.MDAsisst-win.msi`** をダウンロードします。
   > ⚠️ **必ず `.msi` を使用してください。**
   > リリースページには `Ferrotec.MDAsisst-win-Setup.exe` と
   > `Ferrotec.MDAsisst-win-Portable.zip` も並んでいますが、これらは Velopack が自動生成する
   > **個人フォルダ（`%LocalAppData%`）向けの旧方式**です。社内EDR にブロックされて起動できない
   > 既知の不具合（ISS-008）があるため、**使用しないでください**。
   > `.nupkg` / `RELEASES` / `releases.win.json` はアプリの自動更新が内部的に使うファイルで、
   > 手動でダウンロードする必要はありません。
2. ダウンロードした `.msi` ファイルをダブルクリックして実行します。
3. **「このアプリがデバイスに変更を加えることを許可しますか？」という UAC 確認が表示されます。**
   管理者アカウントの認証情報を入力（または「はい」を選択）して進めてください。
4. **「Windows によって PC が保護されました」という青い画面（SmartScreen）が表示される場合があります。**
   これはコード署名（発行元証明）を未取得のため表示されるものです。業務利用が確認されているソフトです。
   - 「詳細情報」をクリックしてください。
   - 「実行」ボタンが表示されるのでクリックしてください。
   - *（画面キャプチャ挿入箇所）*
5. インストールが自動的に進み、完了するとデスクトップおよびスタートメニューにショートカットが
   `Program Files\Ferrotec Corporation\MDAsisst` 配下に作成され、MDAsisst が自動的に起動します。
6. 2回目以降にアプリを更新した際も、UAC 確認は毎回表示されます（管理者権限で書き込む
   Program Files へのインストールのため、これは意図した挙動です）。SmartScreen 警告は
   初回インストール時のみ表示されます。

### 3.2 初期設定項目

初回起動時は既定値で動作します。設定は `設定` 画面（本書 5.3 節）からいつでも変更できます。
設定ファイルの実体は以下に保存されます（通常、直接編集する必要はありません）。

```
%APPDATA%\MDAsisst\settings.json
```

| 分類 | 既定値 | 説明 |
| --- | --- | --- |
| 透過度 | 85% | ウィンドウの半透明の度合い |
| ウィンドウ色 | #1E1E1E（ダーク） | ウィンドウの背景色 |
| 文字色 | #FFFFFF（白） | エディタ・プレビューの文字色 |
| 常に最前面 | ON | 他のウィンドウより手前に表示するか |
| 閉じるボタンの動作 | トレイに格納 | ×ボタンでアプリを終了せずトレイに常駐させるか |
| 自動最小化までの秒数 | 30秒 | 操作しないと画面隅の小さいアイコンに縮小するまでの時間 |
| アップデート方式 | 手動 | 自動／手動／不要から選択（本書 6.3 節） |

## 4. 起動・終了手順

### 4.1 起動方法

- デスクトップまたはスタートメニューの「MDAsisst」アイコンをダブルクリックします。
- 既にトレイに常駐している場合は、タスクトレイ（画面右下）のアイコンをダブルクリックすると
  ウィンドウが再表示されます。

### 4.2 終了手順

| 操作 | 結果 |
| --- | --- |
| ウィンドウ右上の「トレイに格納」ボタン（×アイコン）をクリック | ウィンドウが閉じてトレイに常駐し続けます（アプリ自体は終了しません） |
| トレイアイコンを右クリック →「終了」を選択 | アプリを完全に終了します |

未保存の変更がある状態で終了しようとすると、保存確認のダイアログが表示されます。

### 4.3 自動起動設定

`設定` 画面の「動作」タブで「Windows 起動時に常駐する」にチェックを入れると、
Windows へのログオン時に自動的に MDAsisst がトレイに常駐した状態で起動します。

## 5. 画面・操作説明

### 5.1 画面構成一覧

MDAsisst のメイン画面は、上から「タイトルバー」「ツールバー」「本体（3ペイン）」
「ステータスバー」の4段構成です。*（画面キャプチャ挿入箇所）*

| 領域 | 内容 |
| --- | --- |
| タイトルバー | ファイル名・設定ボタン・最小化ボタン・トレイ格納ボタン |
| ツールバー | 新規・開く・保存、太字/斜体/リンク/表の挿入、レイアウト切替 |
| エディタ（左） | Markdown 本文を入力する領域 |
| プレビュー（中央） | 入力した Markdown の表示結果をリアルタイムに確認できる領域 |
| チートシート（右） | よく使う記法の一覧。検索・ダブルクリックで挿入できる |
| ステータスバー | 保存状態・現在のバージョン番号を表示 |

### 5.2 基本操作

| 操作 | 手順 |
| --- | --- |
| 新規作成 | ツールバー「新規」または `Ctrl+N` |
| ファイルを開く | ツールバー「開く」または `Ctrl+O` |
| 保存 | ツールバー「保存」または `Ctrl+S` |
| 太字にする | 文字を選択して `Ctrl+B`（もう一度押すと解除） |
| 斜体にする | 文字を選択して `Ctrl+I` |
| リンクを挿入 | `Ctrl+K` |
| 表を挿入 | ツールバー「表」ボタン（2行3列の雛形が挿入されます） |
| 箇条書きの継続 | `- 項目` の行末で Enter を押すと次の行にも自動的に `- ` が付きます。
  空の項目で Enter を押すと箇条書きが解除されます |

### 5.3 チートシートの使い方

1. 右側のチートシート欄で見たい記法をキーワード検索できます（例:「表」「リンク」）。
2. 記法の名前と実際の書き方の例が一覧表示されます。
3. 挿入したい項目をダブルクリックすると、カーソル位置に自動で挿入されます。

### 5.4 ウィンドウの半透明・移動・サイズ変更

- ウィンドウ上部（タイトルバー）をドラッグすると自由な位置に移動できます。
- ウィンドウの端にマウスを合わせてドラッグすると、自由にサイズを変更できます。
- 透過度・色・フォントは「設定」画面（本書 6 章）から変更します。

### 5.5 編集時の自動表示／非編集時の自動最小化

- 一定時間（既定30秒）操作をしないと、ウィンドウは画面隅（既定は右下）の小さいアイコンに
  自動的に縮小します。
- 縮小した状態でクリックまたは編集を再開すると、自動的に元の大きさに戻ります。
- この動作の秒数や位置は「設定」画面で変更できます（0秒に設定すると自動最小化を無効化できます）。

## 6. パラメータ（設定）の変更方法

設定はタイトルバーの歯車アイコン、またはトレイアイコンの右クリックメニュー「設定...」
から開きます。

### 6.1 「アピアランス」タブ

| 項目 | 内容 | 変更時の注意 |
| --- | --- | --- |
| 透過度 | スライダーで 20%〜100% の範囲で調整 | 低くしすぎると文字が読みづらくなります |
| ウィンドウ色／文字色 | `#RRGGBB` 形式で入力（例: `#1E1E1E`） | 不正な形式を入力すると既定色に戻ります |
| フォント／文字サイズ | エディタ・プレビューそれぞれ個別に設定可能 | — |

### 6.2 「動作」タブ

| 項目 | 内容 | 変更時の注意 |
| --- | --- | --- |
| 常に最前面に表示 | ON/OFF | OFF にすると他のアプリの後ろに隠れることがあります |
| 閉じるボタンでトレイに格納 | ON/OFF | OFF にすると閉じるボタンでアプリが完全終了します |
| 自動展開／自動最小化までの秒数 | 数値（秒） | 0 を指定すると当該の自動動作が無効になります |
| 最小アイコンの表示位置 | 左上／右上／左下／右下 | — |
| プレビュー更新の遅延 | 数値（ミリ秒） | 小さくすると反応が速くなりますが、PC負荷がやや上がります |
| 自動保存 | ON/OFF、間隔（秒） | ファイルを開いていない（無題）状態では自動保存されません |

いずれの項目も **装置を停止させたり、他システムに影響したりすることはありません**。
安心して調整いただけます。「既定に戻す」ボタンで、いつでも初期状態に戻せます。

### 6.3 「アップデート」タブ

| 方式 | 動作 |
| --- | --- |
| 自動 | バックグラウンドで1日1回**確認のみ**行い、新バージョンがあれば通知する |
| 手動（既定） | 自動では確認しない。「更新を確認」ボタンを押した時のみチェックし、通知する |
| 不要 | 一切ネットワークに接続しない（オフライン専用端末向け） |

いずれの方式でも、新バージョンが見つかった場合の流れは共通です。

1. 「新しいバージョン vX.X.X が公開されています。リリースページを開きますか？」という
   通知ダイアログが表示されます。
2. 「はい」を選ぶと既定のブラウザーでリリースページが開きます。**アプリ自身がファイルを
   ダウンロード・適用することはありません。**
3. 配布されている `.msi` インストーラーをダウンロードし、[3. インストール手順](#3-インストール手順)
   と同じ要領で **上書きインストール**（または旧バージョンをアンインストール後に新規インストール）
   してください。管理者権限（UAC）が必要です。

> **v0.3.1 以降の変更点（ADR-0011）**: v0.3.0/v0.3.1 で発生した「オンライン自動更新の適用直後に
> `FileLoadException`（アクセスが拒否されました）でアプリが起動しなくなる」障害を受け、アプリが
> 自分自身のインストールフォルダ（Program Files 配下）を書き換えて更新を適用する経路
> （旧 `ApplyAndRestart`）を完全に廃止しました。Program Files への配置に移行済み（ADR-0009）
> であっても、未署名のアプリが自分自身の実行ファイルを書き換える挙動そのものが EDR に
> 検知される事例が確認されたためです。**v0.3.2 以降、更新はすべて MSI インストーラーの
> 手動再インストールで行います。** 万一起動しなくなった場合は、いったんアンインストールして
> から MSI を再インストールしてください（[9. トラブルシューティング FAQ](#9-トラブルシューティング-faq)参照）。

## 7. 異常時の対応

本ソフトは装置制御を行わないため、アラーム番号はありません。想定される異常とその対応は
以下のとおりです。

| 事象 | 想定原因 | 対処方法 |
| --- | --- | --- |
| ファイルを開けない | ファイルの破損、アクセス権限不足 | 別のテキストエディタで開けるか確認。開けない場合はファイル自体の破損の可能性があります |
| 保存できない | ディスク容量不足、書き込み権限不足、ファイルが他プロセスで使用中 | 空き容量とファイルの権限を確認してください |
| プレビューが更新されない | 文書が数千行を超える大規模な場合、自動更新が一時停止します（ステータスバーに通知） | `Ctrl+Shift+P` を押すと手動で1回更新できます |
| 更新の確認に失敗する | ネットワーク未接続、社内プロキシ、GitHub側の一時的な制限 | しばらく時間をおいて再試行してください。「不要」設定にしていれば発生しません |
| ウィンドウが最前面に表示されない | 他アプリのフルスクリーン表示、Windows の一時的な制御 | ウィンドウをクリックするか、トレイアイコンから「表示」を選択してください |
| 更新後に `FileLoadException`（アクセスが拒否されました）で起動しない（v0.3.0/v0.3.1） | 旧バージョンのオンライン自動更新機能が Program Files 配下の実行ファイルを自己書き換えし、EDR（Cybereason等）に検知・ブロックされた（ADR-0011） | アプリをアンインストール → `C:\Program Files\Ferrotec.MDAsisst\` フォルダが残っていれば手動削除 → 最新版の `.msi` を再インストール。v0.3.2 以降はこの経路自体を廃止済み |

## 8. メンテナンス

### 8.1 定期メンテナンス

利用者側で定期的に実施すべき作業はありません。ログは自動的に7日を超えると削除されます。

### 8.2 ログの確認方法・保存先

```
%APPDATA%\MDAsisst\logs\mdasisst-yyyyMMdd.log
```

不具合が発生した場合、上記フォルダの最新ログファイルを保守担当へご提供ください。
**ログには編集中の文書の本文は一切記録されません**（機密保持のための設計方針）。

### 8.3 バックアップ・リストア

設定は `%APPDATA%\MDAsisst\settings.json` に保存されています。
PC 入れ替え時などに設定を引き継ぐ場合は、このファイルを新しい PC の同じ場所へコピーしてください。
編集中の Markdown ファイル自体は、通常のファイルと同様にお客様が保存した場所に存在します。

## 9. トラブルシューティング FAQ

| No | 症状 | 確認事項 | 対処 |
| --- | --- | --- | --- |
| 1 | インストール時に SmartScreen 警告が出る | 未署名インストーラーであるため仕様どおり | 「詳細情報」→「実行」で進めてください（3.1節参照） |
| 2 | 起動しても画面が出ない | トレイに常駐している可能性 | タスクトレイのアイコンをダブルクリックしてください |
| 3 | 半透明で文字が見えにくい | 透過度が低すぎる設定になっている | 設定画面で透過度を上げてください |
| 4 | 日本語入力（変換）中に勝手に記号が変換される | 想定される事象ではありません | 発生した場合は再現手順と共に保守担当へご連絡ください |
| 5 | ウィンドウが画面外に出て見えなくなった | マルチモニタ環境でモニタ構成を変更した際に発生し得る | アプリを再起動すると自動的に画面内へ戻る仕様です |
| 6 | 起動直後にウィンドウが出ずプロセスが終了する。イベントビューアーに `FileLoadException ... アクセスが拒否されました` が記録される | 社内EDR（Cybereason 等）がアプリの実行ファイルをブロックしている可能性があります（v0.2.x で実際に発生した事象） | v0.3.0 以降の `.msi` で再インストールしてください。それでも解消しない場合は、情報システム部門に「Cybereason 管理コンソールで当該端末の `MDAsisst.exe` / `MDAsisst.dll` の検知有無を確認し、必要なら除外登録する」よう依頼してください |
