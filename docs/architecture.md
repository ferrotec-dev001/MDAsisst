# MDAsisst アーキテクチャ設計書

## 1. システム構成
- **UI層 (WPF)**: MVVM パターン (CommunityToolkit.Mvvm等) を採用。半透明・ドラッグ移動・サイズ変更・トレイ常駐をサポートするカスタムウィンドウ。
- **エディター・プレビューコア**: AvalonEdit または WebView2 / Markdig による Markdown レンダリング・スニペット補完。
- **設定管理**: JSON形式によるローカル設定ファイル（アピアランス、透過度、常駐設定、自動非表示タイマー等）。
- **アップデート機能**: GitHub API / Releases を利用したバージョン確認とインストーラーのバックグラウンド取得・適用。

## 2. ディレクトリ構成案
- `src/` : ソースコード (.sln, WPFプロジェクト)
- `docs/` : MD駆動設計用ドキュメント (要件定義、アーキテクチャ、タスク・ロードマップ)
- `installer/` : インストーラー構築スクリプト
